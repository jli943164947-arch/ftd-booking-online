# FTD预约网站

这是一个可在线部署使用的网站版本，功能与 FTD 微信预约小程序保持一致。

## 功能

- 新增预约：填写日期、开始时间、结束时间、姓名、工号、教员/学员身份。
- 每场最多 5 人。
- 仅周三至周五可预约，最远可预约未来一个月。
- 新增预约页面备注时间段：0800-1100、1200-1400、1410-1610、1620-1820。
- 自动阻止时间重叠预约，相邻时间可以连续预约。
- 可切换查看未来一个月计划和历史预约记录。
- 可导出 Excel，格式为日期逐行显示，每个预约一个横向单元格。
- 导出 Excel 单元格固定四行：第一行时间，第二行教员，第三行学员，第四行学员。

## 本地启动

```bash
npm start
```

启动后打开：

```text
http://localhost:3000
```

## 在线部署

把整个 `ftd-booking-online` 文件夹上传到支持 Node.js 的服务器或平台，然后运行：

```bash
npm start
```

服务器会通过 `PORT` 环境变量自动适配平台端口；如果没有设置，则默认使用 `3000`。

### Render

1. 登录 Render。
2. 新建 Web Service。
3. 上传或连接本项目。
4. 启动命令填写 `node server.js`。
5. 部署完成后，Render 会提供固定网址。

项目已包含 `render.yaml`，连接 Git 仓库时可直接识别。

### Railway / Heroku 类平台

项目已包含 `Procfile` 和 `package.json`。

启动命令：

```bash
node server.js
```

## 数据说明

预约数据统一保存在服务器的 `data/reservations.json` 文件中。部署到线上后，多个人打开同一个网址会看到同一份预约记录。

如果平台每次重启会清空文件系统，需要额外挂载持久化磁盘，或改接数据库。
